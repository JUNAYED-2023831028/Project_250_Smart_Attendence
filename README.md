# App Name: Smart Attendance

## What the app does
Attendance Management System is a smart mobile app for taking attendance using a Dynamic QR Code.

## Why we made it
The app is made to save time and reduce manual work.

## How it works
1. The teacher selects the course and batch.
2. The teacher creates a Dynamic QR Code.
3. Students scan the QR Code.
4. Attendance is submitted in real time.

## Main Features
1. Dynamic QR Code Attendance
2. Anti-Proxy System
3. Role-Based Access
4. Attendance History and Reports

## Technologies Used
- Flutter
- Dart
- Firebase Authentication
- Cloud Firestore
- Firebase Storage
