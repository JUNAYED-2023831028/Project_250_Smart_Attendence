#App Name: Smart Attendance.

#What the app does :
Attendance Management System is a smart mobile app for taking attendance using a Dynamic QR Code. It helps teachers to manage attendance easily.

#Why we made it:
The app is made to save time and reduce manual work. It also helps stop fake or proxy attendance and keeps attendance records safely in digital form.

#How it works:
1.The teacher selects the course and batch and creates a Dynamic QR Code for the class.
2.The QR Code works for only 2 minutes.
3.The QR Code rotates every 30 seconds for better security.
4.Students use their own accounts to scan the QR Code with their phone camera.
5.The attendance is submitted in real time.
6.The admin manages teachers, students  and subjects.

#Main Features :
1.Dynamic QR Code Attendance:
Students can give attendance by scanning the QR Code created by the teacher.
2.Anti-Proxy System:
The QR Code rotates every 30 seconds and expires after 2 minutes. This makes proxy attendance very difficult.
3.Role-Based Access:
There are two types of users: Student and  Teacher . Each user has different features and access. Admin is also an user who manages teachers , students and courses.
4.Attendance History and Reports:
Students and teachers can check attendance history and records.
